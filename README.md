# مدونة 3bot

واجهة عربية عامة باتجاه RTL لمدونة تقنية، بهوية بصرية مستقلة ووضعين داكن وفاتح. تدعم منشورات نصية بلا حد ظاهر لعدد الأحرف، ورفع صور وفيديوهات مباشرة إلى Cloudinary، واستطلاعات وتصويت، ولوحة إدارة بسيطة لمراجعة المشاركات وإخفائها أو إظهارها وحذف المخالف منها.

الخادم Express وقاعدة البيانات MySQL/MariaDB عبر `mysql2`. الإصدار الحالي وفق `package.json`: **2.7.0**. الموقع المنشور على Vercel: https://3bot-blog.vercel.app

## الميزات

- منشورات نصية بلا حد ظاهر لعدد الأحرف، تُحفظ في MySQL وتُعرض مع الحفاظ على فواصل الأسطر. في الخلاصة العامة يظهر زر «اقرأ المزيد» للمنشورات الطويلة.
- رفع صور (`JPG` / `PNG` / `WEBP` / `GIF`) وفيديوهات (`MP4` / `WEBM`) حتى 25 ميغابايت للملف، من المتصفح مباشرة إلى Cloudinary بعد التحقق من النوع والحجم، وبإصدار توقيع من الخادم دون كشف السر. إن لم تُضبط بيانات Cloudinary، يستمر نشر النصوص والاستطلاعات ويتوقف رفع الوسائط برسالة واضحة.
- استطلاعات رأي (خياران إلى 6 خيارات) مع شريط نتائج. يُحفظ التصويت في قاعدة البيانات، ويُسمح بتصويت واحد لكل معرّف متصفح. هذا ليس توثيق هوية، ويمكن التحايل عليه بمسح التخزين المحلي أو استخدام متصفح مختلف.
- القراءة والتصويت متاحان للزوّار بدون تسجيل دخول. النشر ورفع الوسائط متاحان لصاحب المدونة فقط بعد تسجيل الدخول في `/admin`. تبقى حدود معدل الطلبات قائمة. لا ترفع محتوى خاصًا أو حساسًا.
- لوحة الإدارة على `/admin` محمية بكلمة مرور من متغير البيئة `ADMIN_PASSWORD`. منها يمكن استعراض المشاركات وإخفاؤها أو إظهارها وحذف المخالف منها مع الملفات المرتبطة في Cloudinary. الصفحة غير مرتبطة من الواجهة العامة. المنشورات المخفية تختفي عن الزوّار ويتوقف التصويت عليها.
- زر في الترويسة للتبديل بين الوضع الداكن والفاتح. الاختيار يُحفظ في المتصفح، والوضع الافتراضي يتبع إعداد النظام.
- إشعارات Toast عربية قابلة للإغلاق عند نجاح النشر أو التصويت أو الحذف وعند الأخطاء، وتختفي تلقائيًا بعد نحو 5.5 ثانية، مع أدوار ARIA مناسبة لقارئات الشاشة. لا تستخدم هذه الميزة إشعارات المتصفح أو الإشعارات الفورية.

## المتطلبات

- Node.js **22 أو أحدث** (ملف `package.json` يحدد `"engines": { "node": ">=22" }` و`packageManager` هو `npm@10.9.9`).
- قاعدة بيانات MySQL أو MariaDB متوافقة (مثل TiDB Cloud Starter عند النشر مع Vercel).
- حساب Cloudinary إن رغبت في رفع الصور والفيديو.
- انسخ `.env.example` إلى `.env` وعدّل القيم. لا تضع أسرارًا في ملفات الواجهة أو في Git.

## المتغيرات

التطبيق يقرأ المتغيرات التالية من بيئة التشغيل فقط:

- `DATABASE_URL` (إن وُجد يُستخدم أولًا)
- أو بديلًا: `DB_HOST` و`DB_PORT` (الافتراضي 4000) و`DB_USER` و`DB_PASSWORD` و`DB_NAME`
- `DB_SSL` أو `DB_SSL_MODE` (اختياري؛ `disabled` لتعطيل TLS محليًا مع المتغيرات المنفصلة)
- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET` (الصق السر الحقيقي دون علامات اقتباس، وليس القيمة المقنّعة التي تظهر كنجوم)
- `ADMIN_PASSWORD`
- `SESSION_SECRET`
- `PORT` (اختياري، الافتراضي 3000)
- `DB_CONNECTION_LIMIT` (اختياري؛ الافتراضي 1 على Vercel و5 محليًا)

إن نقص إعداد قاعدة البيانات لا يتوقف الخادم عن تقديم الصفحة العامة ولوحة الإدارة، وتعيد واجهات `/api` رسالة عربية بحالة 503. وإن نقص `ADMIN_PASSWORD` أو `SESSION_SECRET` تظهر في `/admin` رسالة بأن اللوحة غير مفعّلة.

## التثبيت والتشغيل المحلي

```sh
npm ci
npm start
```

لل تطوير مع إعادة التشغيل عند تغيّر الملفات (`node --watch server.js`):

```sh
npm ci
npm run dev
```

يستمع التطبيق إلى المنفذ `PORT` (الافتراضي 3000)، وينشئ جداول المحتوى والاستطلاعات بطريقة إضافية عند الإقلاع (وكذلك عند أول طلب في بيئة Serverless)، ويضيف الترحيلات اللازمة مثل عمود `media_public_id`. مسار جاهزية النشر `/_health`.

لا يوجد سكربت اختبار في `package.json`.

## التشغيل عبر Docker

المستودع يتضمّن `Dockerfile` يعتمد على `node:22-alpine`، ويثبّت الاعتماديات بـ `npm ci --omit=dev`، وينسخ `server.js` ومجلد `public/`، ويعرّض المنفذ 3000، ثم يشغّل `node server.js`.

```sh
docker build -t 3bot-blog .
docker run --publish 3000:3000 --env-file .env 3bot-blog
```

مرّر متغيرات البيئة المطلوبة (من `.env.example`) عند التشغيل.

## النشر على Vercel

المشروع مهيأ للتشغيل كدالّة Express عبر `api/index.js` و`vercel.json`، مع تقديم ملفات `public/` من الخادم. حد طلبات دوال Vercel نحو 4.5 ميغابايت؛ لذلك رفع الفيديو حتى 25 ميغابايت يتم مباشرة إلى Cloudinary وليس عبر الدالة.

خطوات إعداد قاعدة البيانات ومتغيرات البيئة على Vercel موضّحة في [PROJECT.md](PROJECT.md). رابط الإنتاج المذكور في المشروع: https://3bot-blog.vercel.app
