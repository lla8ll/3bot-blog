# مدونة 3bot

واجهة عربية عامة باتجاه RTL بهوية بصرية مستقلة لمدونة تقنية، مع وضعين داكن وفاتح، ومنشورات نصية بلا حد ظاهر لعدد الأحرف، رفع صور وفيديوهات مباشرة إلى Cloudinary، استطلاعات وتصويت، ولوحة إدارة بسيطة لحذف المشاركات المخالفة. الخادم Express وقاعدة البيانات MySQL، والموقع منشور على Vercel: https://3bot-blog.vercel.app

## الوظائف

- البيانات والسجلات تُحفظ في قاعدة بيانات MySQL.
- ملفات الصور والفيديو (JPG/PNG/WEBP/GIF وMP4/WEBM) تُرفع من المتصفح مباشرة إلى Cloudinary حتى 25 ميغابايت للملف، بعد التحقق من النوع والحجم في المتصفح، وبإصدار توقيع من الخادم دون كشف سر الواجهة. إن لم تُضبط بيانات Cloudinary، يستمر نشر النصوص والاستطلاعات ويتوقف رفع الوسائط برسالة واضحة.
- التصويت يُحفظ في قاعدة البيانات؛ يسمح بتصويت واحد لكل معرّف متصفح. هذا ليس توثيق هوية، ويمكن التحايل عليه بمسح التخزين المحلي أو استخدام متصفح مختلف.
- القراءة والتصويت متاحان للزوّار بدون تسجيل دخول. النشر ورفع الوسائط متاحان لصاحب المدونة فقط بعد تسجيل الدخول في `/admin`. تبقى حدود معدل الطلبات قائمة. لا ترفع محتوى خاصًا أو حساسًا.
- لوحة الإدارة على `/admin` محمية بكلمة مرور من متغير البيئة `ADMIN_PASSWORD`. منها يمكن استعراض المشاركات وحذف المخالف منها مع الملفات المرتبطة في Cloudinary.
- زر في الترويسة للتبديل بين الوضع الداكن والفاتح. الاختيار يُحفظ في المتصفح، والوضع الافتراضي يتبع إعداد النظام.

## المتغيرات

انسخ `.env.example` إلى `.env` وعدّل القيم. التطبيق يقرأ المتغيرات التالية من بيئة التشغيل فقط ولا يضعها في ملفات الواجهة:

- `DATABASE_URL` (إن وُجد يُستخدم أولًا)
- أو بديلًا: `DB_HOST` و`DB_PORT` (الافتراضي 4000) و`DB_USER` و`DB_PASSWORD` و`DB_NAME`
- `DB_SSL` أو `DB_SSL_MODE` (اختياري؛ `disabled` لتعطيل TLS محليًا مع المتغيرات المنفصلة)
- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET` (الصق السر الحقيقي دون علامات اقتباس، وليس القيمة المقنّعة التي تظهر كنجوم *)
- `ADMIN_PASSWORD`
- `SESSION_SECRET`
- `PORT` (اختياري، الافتراضي 3000)
- `DB_CONNECTION_LIMIT` (اختياري؛ الافتراضي 1 على Vercel و5 محليًا)

## التشغيل المحلي

```sh
npm ci
npm start
```

يستمع التطبيق إلى المنفذ `PORT` (الافتراضي 3000)، وينشئ جداول المحتوى والاستطلاعات بطريقة إضافية عند الإقلاع (وكذلك عند أول طلب في بيئة Serverless)، ويضيف عمود `media_public_id` إن لم يكن موجودًا. مسار جاهزية النشر `/_health`. إن نقص إعداد قاعدة البيانات لا يتوقف الخادم عن تقديم الصفحة العامة ولوحة الإدارة، وتعيد واجهات `/api` رسالة عربية بحالة 503.

خطوات النشر على Vercel وإعداد قاعدة البيانات موضّحة في `PROJECT.md`.

## إشعارات داخل الموقع

تظهر رسائل Toast عربية مخصصة عند نجاح النشر أو التصويت أو الحذف وعند أخطاء التحقق والإرسال. الإشعارات قابلة للإغلاق وتختفي تلقائيًا بعد نحو 5.5 ثانية، وتستخدم أدوار ARIA المناسبة لقارئات الشاشة. لا تستخدم هذه الميزة إشعارات المتصفح أو الإشعارات الفورية.
